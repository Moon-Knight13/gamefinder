Why this exists

Availability intelligence, not one-off polls

Every scheduling bot optimizes for "find one best time for one event." GameFinder optimizes for "show me the landscape so I can make better decisions over time."

📅

Components V2 Calendar

Interactive weekly grid built with Discord's latest UI. One-tap toggles, custom hours, recurring patterns — all inside Discord.

🎯

Oneshot + Campaign

Combined view: best single dates for a oneshot, plus consistent weekly slots reliable for recurring campaigns.

✅

Five-tier RSVP

Going, Maybe, Can't, Spectator, Waitlist. Quorum auto-creates a Discord Event. Going players get a DM with the event link.

🌍

Timezone-native

All times use Discord timestamps — every player sees their own timezone automatically. Set once, never think about it again.

🎲

Post Game Modal

See a viable window? One click opens a modal. Title, description, player cap — game is live in the scheduling channel with RSVP buttons.

🛡️

Privacy by design

Minimal data: Discord IDs, timezone, availability blocks. Auto-purged. Delete on request. Guild-isolated queries prevent cross-server leakage.

Architecture

How it's built

Single-process Python bot. No external services. SQLite handles the scale.

Cogs

availability, windows, games, campaigns, admin — each handles one domain with slash commands and persistent views.

UI Layer

discord.py 2.7+ Components V2: LayoutView, Container, Section for rich interactive calendar and windows.

Database

SQLite + WAL mode via aiosqlite. 10 tables, every query scoped by guild_id. Auto-migration on startup.

guilds users availability recurring_availability games rsvps campaigns campaign_roster sessions

Scheduler

APScheduler: auto-purge stale availability, 24h game reminders, session-day pings, hourly widget updates.

Testing

61 tests: unit, BDD scenarios, stress tests. Factory generates realistic TTRPG parties with configurable archetypes.

Deploy

Oracle Cloud free tier ARM VM. Docker Compose. GitHub Actions CI. No exposed ports, no domain needed.
